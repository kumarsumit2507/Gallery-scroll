Smooth Horizontal Image Gallery

A modern, responsive horizontal image gallery featuring mouse-wheel scrolling, smooth navigation arrow buttons, and hover animation effects.

Features

1. Mouse Wheel Horizontal Scrolling: Convert vertical mouse wheel movements into smooth horizontal scrolling.

2. Button Navigation: Dedicated "Back" and "Forward" arrow buttons for controlled navigation.

3. Hover Effects: Grayscale-to-color transition with a smooth image scale animation.

4. Cross-Browser Support: Hidden default scrollbars across Chrome, Safari, Edge, and Firefox.

Project Structure

Make sure your project files are organized.


⚠️ Important Note for Setup

To get this code to work properly, you must create an assets folder in your root directory and populate it with 9 or more images. The layout relies on multiple image containers to enable the horizontal scrolling behavior.
